Erro de Compilação - sc_start4 com flags

O problema é que a macro sc_start4 não aceita flags SCSTART como argumento extra.

CORREÇÃO:

Substituir as duas chamadas de sc_start4 que estão com flags:

LINHA 3742 (atual - ERRADA):
sc_start4(src, bl, SC_SPIRIT_SAGE_MARK, 100, 0, 0, src->id, 0, 10000, SCSTART_NOAVOID|SCSTART_NOTICKDEF|SCSTART_NORATEDEF);

CORREÇÃO (usar status_change_start diretamente):
status_change_start(src, bl, SC_SPIRIT_SAGE_MARK, 10000, 0, 0, src->id, 0, 10000, SCSTART_NOAVOID|SCSTART_NOTICKDEF|SCSTART_NORATEDEF);

LINHA 3748 (atual - ERRADA):
sc_start4(src, src, SC_SPIRIT_SAGE_CD, 100, 0, 0, 0, 0, 2000, SCSTART_NOAVOID|SCSTART_NOTICKDEF|SCSTART_NORATEDEF);

CORREÇÃO:
status_change_start(src, src, SC_SPIRIT_SAGE_CD, 10000, 0, 0, 0, 0, 2000, SCSTART_NOAVOID|SCSTART_NOTICKDEF|SCSTART_NORATEDEF);

NOTA: A macro sc_start4 multiplica o rate por 100 automaticamente, então quando usar status_change_start diretamente, precisa passar 10000 (100 * 100) ao invés de apenas 100.
